# VALORANT マップルーレット

VALORANT のマップをランダムに決めるルーレットと、BO３のカスタムマッチやスクリムで便利なBAN/PICK

## 使い方

###　ルーレットの使い方

1. マッププールから抽選したいマップを選びます。（デフォルトでは全て抽選対象）外したいマップがあればそのマップをクリックして抽選対象から外して下さい。
2. SPINをクリックするとマップが自動的に選ばれます。

###　BAN/PICKの使い方

1. 左上のボタンからBO3モードに切り替えてください。
2. チーム名と先攻・後攻、マップを７マップ選択してください。マップと先攻・後攻が決まった後、「BAN/PICKを開始する」を押してBAN/PICKを開始します。
3. 先攻から最初にBANするマップを選択してください。
4. 次に後攻は、残ったマップからBANするマップを選択してください。
5. 先攻は残ったMAPからPICKするマップを選択してください。
6. 後攻は先攻がPICKしたマップのアタッカーかディフェンダーの攻守を選択してください。
7. 同様にMAP3まで決めていきましょう。
8. 決めた結果を基に試合を行ってください。結果をDiscordなどに簡単に共有できるように、テキストでコピーできる機能があります。左上のコピーを押して、そのままDiscordに貼り付けてください。
 - マークダウンと絵文字を使用しています。マークダウンや絵文字ができない環境では、<":blue_circle:">のように正しく表示されない可能性があります。（読みづらいですが、認識できる範囲だと思います。）


## 機能

###　ルーレットの機能

- マッププールの全選択・全解除ができます。
- 出たマップは自動でチェックが外れる機能がデフォルトでオンになっています。オフにもできます。
- 回転時間の長さを切り替えられます。（短い・ふつう・長い）
- 出たマップは履歴が出ます。SPINの横には直近３マップの記録が、
  - 「履歴を詳しく見る」を押すことですべての履歴を確認することができます。

###　BAN/PICKの機能

- 特段言及する機能はありません。使い方に従ってBAN/PICKを行ってください。
